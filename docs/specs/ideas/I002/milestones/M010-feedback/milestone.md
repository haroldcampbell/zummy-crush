# Milestone: I002-M010 - Feedback UX Improvements

## Principles Reference

- See `docs/principles.md` for non-negotiable workflow rules (including PR merge approval).

## Goal

Improve onboarding clarity and UI polish based on playtest feedback without changing core mechanics.

## Scope (In)

- Scoring guide layout improvements (tabs, tile visuals, power-up explanations)
- HUD/controls polish (remove Ready text, relocate Info button)
- Board panel sizing fix
- Tile background adjustments for resting vs dragging and VFX proximity cues

## Scope (Out)

- New gameplay mechanics
- Audio/haptics

## Success Criteria

- Scoring guide is concise, visual, and explains power-ups clearly
- Bottom status "Ready" is removed and controls are still discoverable
- Board panel no longer grows with page height
- Tile background changes are noticeable only during interaction or VFX proximity
