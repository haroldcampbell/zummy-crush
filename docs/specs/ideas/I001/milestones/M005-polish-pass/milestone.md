# Milestone: M005 - Polish Pass

## Principles Reference

- See `docs/principles.md` for non-negotiable workflow rules (including PR merge approval).

## Goal

Run a focused visual/UX polish pass that experiments with tile readability, alternate tile presentation, HUD typography, and a DnD-styled background.

## Scope (In)

- Reduce the match letter set to improve readability and speed
- Explore alternate tile presentation (gems, dots, etc.)
- Update HUD layout and typography for clearer hierarchy
- Introduce a DnD-styled background treatment
- Revisit tile sizing/spacing for readability

## Scope (Out)

- New power-ups or loot mechanics
- Economy changes
- Audio overhaul

## Success Criteria

- At least one candidate visual direction is selected for each experiment area
- Readability improves in quick playtests at 360 x 640
- Changes remain reversible/configurable

## Specs

- [ ] S001 - Reduce Letter Set for Matching
- [ ] S002 - Alternate Tile Presentation Experiment
- [ ] S003 - HUD Layout + Typography Refresh
- [ ] S004 - DnD Background Treatment
- [ ] S005 - Tile Readability (Size/Spacing) Pass

## Dependencies

- M002 board expansion
- M004 match-5 slice (for visual consistency across tiers)

## Risks

- Visual changes may reduce clarity or slow recognition
- Over-polish without decisions could stall next milestones
