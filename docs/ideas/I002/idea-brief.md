# Game Brief: Rotate and Match

## Intent

Create a match-3 puzzle where the core skill is rotating entire rows or columns, producing a distinctive wrap-and-snap feel before matches resolve.

## Concept Summary

- Players drag a single row or column per move.
- The dragged line rotates and wraps within itself (row wraps horizontally, column wraps vertically).
- Matches resolve only after release and snap-in; then standard match-3+ resolution happens (straight lines only).
- Tiles fall with gravity and refill after clears (same as I001).

## Platform + Experience

- Mobile-first, short session puzzle.
- Emphasis on tactile “rotation” feel and quick read of line outcomes.

## Near-Term Scope (Now)

- Prototype row/column drag + wrap mechanic.
- Match-3+ resolve after snap-in (no mid-drag matches).
- Gravity/cascade/refill aligned with I001.
- Thematic tile set (non-letter) with 4 base tiles.
- Power-up variants derived from the same 4 base tiles.

## Future Exploration (Later)

- Alternative power-up activation rules for rotation moves.
- New match patterns or special rotations.
- Additional tile set themes or readability experiments.
