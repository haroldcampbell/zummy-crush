# Hypotheses (I002)

## Core Loop

- Players understand the rotate-and-wrap input within 30 seconds without explanation.
- The snap-then-resolve timing improves clarity vs mid-drag matching.
- Four base tile types are enough for readable planning without feeling repetitive.

## Progression + Rewards

- Power-up variants based on the four base tiles are easy to identify.
- Rotation-based moves feel distinct enough to support separate loot/power-up rules later.
